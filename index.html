[CAT] Cilent

A small, read-only match data and quality-of-life add-on for Territorial.io, made for [CAT]. It adds live match statistics and optional manual opening presets. It does not send attacks or automate gameplay.

Install with Tampermonkey Save the .user.js file

Install

  1. Install Tampermonkey in your browser. In Chrome, enable Allow User Scripts for the extension if prompted.
  2. Click Install with Tampermonkey above and confirm the install in Tampermonkey.
  3. Visit territorial.io and start a match.

Downloaded the file instead? Do not double-click it in Windows Explorer: Windows Script Host will show a syntax error. In Tampermonkey’s Dashboard → Utilities → URL, import https://cybercathacker.github.io/cat/CAT-Cilent.user.js.

This add-on reads the game client in your browser. It is not an official Territorial.io product and is not affiliated with the game’s owner. Compatibility can change when the game updates.
